# Cara Kirim Pesan

## Langkah:
1. **Close Unity** → buka lagi
2. Menu: **Tools → 3D AI Assistant → Setup Scene**
3. Pilih **VRMLoader** → isi Vrm Path: `Assets/Models/2119591849329468324.vrm`
4. **Ctrl+S** save
5. **Play**

## Setelah Play:
1. Di bawah layar ada **kolom input** (gelap) + tombol **"Kirim"** (biru)
2. **Klik kolom input** → ketik pesan
3. **Tekan Enter** atau klik **"Kirim"**
4. Tunggu beberapa detik → AI respon + suara
